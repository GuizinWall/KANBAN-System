# 🌌 NEXUS KANBAN SYSTEM v2.0

Um gerenciador de tarefas funcional com estética *dark/cyberpunk* luminescente, desenvolvido com tecnologias web puras. A aplicação permite a organização de atividades em um fluxo Kanban dinâmico e o acompanhamento de indicadores de produtividade em tempo real diretamente no navegador.

Este projeto atende aos requisitos de avaliação de nível básico de desenvolvimento web front-end.

## 🚀 Tecnologias Utilizadas

* **HTML5:** Estruturação semântica das colunas, formulários de entrada e painel de controle.
* **CSS3 Avançado:** Interface responsiva, animações customizadas (*Glow Pulse*), efeitos de luminescência (*neon glow*) e texturas digitais (*scanlines*).
* **JavaScript (ES6+):** Manipulação dinâmica do DOM, controle de estado dos cards, cálculo de métricas e renderização fluida.
* **localStorage:** Persistência de dados local (armazenamento nativo do navegador), dispensando a necessidade de banco de dados externo ou APIs.
* **Git & GitHub:** Versionamento de código e hospedagem do repositório.

## 🛠️ Funcionalidades Implementadas

* **Cadastro Automatizado:** Adição de tarefas com definição de títulos e níveis de prioridade (Alta, Média, Baixa).
* **Tags de Prioridade:** Identificação visual imediata do nível de criticidade de cada atividade com badges estilizadas.
* **Fluxo Kanban Completo:** Divisão de tarefas por estágios operacionais (*A Fazer*, *Em Andamento* e *Concluído*).
* **Indicadores Dinâmicos:** Contadores numéricos reativos para cada coluna do quadro.
* **Barra de Eficiência Quântica:** Barra de progresso integrada que calcula e exibe em tempo real a porcentagem de tarefas concluídas.
* **Persistência Local:** Salvamento automático das alterações. Os dados não expiram ao fechar ou atualizar a aba.

## 📦 Como Executar a Aplicação

A aplicação funciona inteiramente no lado do cliente (*client-side*), sem qualquer dependência de servidores backend.

1. **Clone este repositório:**
   ```bash
   git clone https://github.com
   ```
2. **Acesse o diretório do projeto:**
   ```bash
   cd nexus-kanban-system
   ```
3. **Inicialize a interface:**
   * Dê um duplo clique no arquivo `index.html` para executá-lo diretamente no seu navegador, ou
   * Utilize a extensão **Live Server** do VS Code para rodar o ambiente localmente.
